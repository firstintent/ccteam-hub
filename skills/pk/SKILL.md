# PK — 多 vendor 同台竞速

让多个 vendor 并行做同一件事,再盲评对比、给用户推荐。选手 = session,裁判 = 你。全程用 ccteam 的 session 工具,不写代码。

## 步骤

1. **定选手**:默认两个 —— 同一 role 配不同 vendor(`claude` vs `codex`)= 比引擎;不同 role = 比角色。用户可加到 N 个。
2. **并行派发**:每个选手 `session_spawn{role, vendor}` 拿 sid(role 必填、需已存在;vendor 默认 `claude`),再把**完全一样**的任务原样 `session_dispatch{sid, task}` 发给每一个。先全部派完再去收,确保真并行。
3. **收齐**:每个 sid `session_collect{sid}`(用上次见到的 turn_id 作 `since` 取增量);没跑完会返回空,稍后重试,直到人人有终稿。
4. **盲评对比**:结果摆齐,标"方案 A/B"评、别因厂商偏心。默认按 正确性 > 安全 > 可维护/简洁 > 性能(或用户给的标准);涉及改代码就比产物/diff,不只比说辞。
5. **给推荐,用户拍板**:输出每个选手的优点/风险 + 一个推荐赢家及理由,连同各自结果交给用户**选**——不自动采纳。
6. **收尾**:用户定了后 `session_stop` 掉没选中的选手,别留着空跑。

## 变体

只换法、不改流程:N 个选手、任意 vendor/role、判法换成评分卡 / 锦标赛 / best-of-N / 把多方合成更优的一版,或同题给各人不同角度。
